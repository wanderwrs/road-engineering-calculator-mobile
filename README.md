# 道路工程计算器 · 移动版

面向道路与桥梁工程技术专业的**移动端优先**纯前端计算工具集合。支持本地记录保存、PDF 导出与离线浏览，数据不上传服务器。

## 功能特性

- **10 个专业计算器**，按类别分组：砂石材料、水泥实验、混凝土配合比、通用工具
- **移动端适配**：响应式布局，侧边栏抽屉式导航，适配手机/平板/桌面
- **本地记忆**：计算记录自动保存到浏览器 `localStorage`，可随时查看、再次计算、删除
- **资料查看**：历史记录列表，一键恢复计算器
- **PDF 导出**：计算结果可导出为 PDF，内含输入参数、计算结果与免责声明
- **深色模式**：支持浅色/深色主题切换

## 计算器清单

| 类别 | 计算器 |
|------|--------|
| 砂石材料 | 砂子堆积密度、砂筛分实验、石子针片状 |
| 水泥实验 | 水泥细度、水泥标准稠度用水量、水泥胶砂强度 |
| 混凝土配合比 | 水灰比、混凝土坍落度、灰砂比 |
| 通用工具 | 度分秒计算 |

## 技术栈

- 纯 HTML + CSS + JavaScript（无构建工具）
- Font Awesome 4.7（图标）
- jsPDF（PDF 导出）

## 本地运行

任意静态服务器即可：

```bash
cd road-calc-mobile
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

或直接双击 `index.html` 打开。
